How to Play

Please select the application you want to use!

MafiaPS Mobile APK

  • Uninstall Real Growtopia if you have it
  • Restart your device (optional but recommended)
  • Install MafiaPS APK
  • Open MafiaPS APK use your MafiaPS account to login

MafiaPS Windows Installer

  • Uninstall Real Growtopia if you have it
  • Install MafiaPS APK
  • Open MafiaPS Installer MafiaPS account to login
  • Wait until installing succes, then login MafiaPS account to login

Windows (hosts)

Press Win+R → paste C:\Windows\System32\drivers\etc

Open hosts with Notepad (Admin)

103.126.117.167 www.growtopia1.com
103.126.117.167 www.growtopia2.com

Save → launch Growtopia

PowerTunnel (Android)

  • Install PowerTunnel APK
  • Open → Plugin → Hosts → Open the Setting
  • Enter: https://growtopia.id/android
  • Back, Click "CONNECT" button, open Growtopia

Hosts Go (Android)

  • Install Hosts Go (No Root)
  • Open → Hosts Editor → enable → Download Hosts File
  • Enter: https://growtopia.id/android
  • Apply, start protection, open Growtopia

Virtual Host (Android)

  • Install Virtual Host APK
  • Download Hosts File here
  • Open → SELECT HOSTS FILE
  • Select the downloaded host file (MAFIAPS-HOST (2).txt)
  • open Growtopia

Mac

Finder → Go → Go to Folder → /private/etc/hosts

Copy to Desktop, edit, then add:

103.126.117.167 www.growtopia1.com
103.126.117.167 www.growtopia2.com

Save and move back → start Growtopia

Surge5 (iPhone)

  • Install Surge5
  • Import Profile: https://growtopia.id/ios
  • Allow VPN Configuration → Connect → Open Growtopia

MafiaPS | The Growtopia Private Server

PT MAFIA JAYA — Founded on October 10, 2023, by Fery, MafiaPS has grown into a thriving community with over 19,000 members. More than just a game, it's a space where creativity and exploration come to life.

MafiaPS is a safe, welcoming, and inclusive server with strong moderation and a zero-tolerance policy for disruptive behavior. Players can enjoy the game without worry, focusing on building, learning, and connecting with others.

What started as a simple tree-growing server has expanded into something much bigger. Players can take on different roles, from becoming a surgeon and saving lives to mastering the art of cooking, fishing for rare catches, building ships for exploration, or creating challenging parkour worlds filled with puzzles and obstacles.

With so many possibilities, MafiaPS offers a unique experience where every player can find their own path. Whether you're here to create, compete, or simply explore, the choice is yours.
