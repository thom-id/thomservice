Download Indonesia APK - Android

PowerTunnel (Android)

  1. 1 Download PowerTunnel APK dan instal.
  2. 2 Buka aplikasi lalu pencet tombol bergambar titik tiga-list di sebelah kiri tombol bergambar gir.
  3. 3 Pencet tombol bergambar gir di opsi "Hosts".
  4. 4 Copy dan paste Server link pada opsi "Hosts File URL".
  5. 5 Pencet tombol "Connect" dan cobalah login melalui Growtopia.

Virtual Host (Android)

  1. 1 Download Virtual Host APK dan instal.
  2. 2 Buka aplikasi lalu pencet tombol RE-SELECT HOSTS FILE.
  3. 3 Pencet Host yang sudah di download.
  4. 4 Download Host Server link pada opsi "Hosts File URL".
  5. 5 Cobalah login melalui Growtopia.

Windows

  1. 1 Press ⊞ Win+R (Windows Key + R) to open the "Run" window.
  2. 2 Type C:\Windows\System32\drivers\etc in the textbox.
  3. 3 Find the file named hosts.
  4. 4 Right-click on the "hosts" file and edit it with Notepad/text editor.
  5. 5 Copy the Server IP Below and Paste it in the file.
  6. 6 Save, then log in to your Growtopia.

IOS / SURGE 5

  1. 1 Install Surge di iPhone / iPad kamu.
  2. 2 Salin konfigurasi Surge menggunakan Server Link.
  3. 3 Buka Surge → import konfigurasi dari clipboard.
  4. 4 Aktifkan Surge - Growtopia akan diarahkan ke server kami.
  5. 5 Buka Growtopia dan selamat bermain!
