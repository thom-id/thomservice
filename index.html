How to Play

Pilih aplikasi yang ingin digunakan!

AURIX APK - Android

Hapus Growtopia asli dulu jika ingin menggunakan aplikasi AURIX.

Langsung login tanpa Virtual Host / PowerTunnel.

Download AURIX APK

PowerTunnel

  1. 1 Install PowerTunnel di perangkat
  2. 2 Buka → ☰ → Hosts → Host file URL
  3. 3 Klik tombol "Salin Host" di bawah lalu Paste
  4. 4 Hosts file update period → On start
  5. 5 Kembalikan hingga ketemu connect (merah)
  6. 6 Connect hingga menjadi disconnect (hijau)
  7. 7 Buka Growtopia → Play → name server LucidPS
Download PowerTunnel

Virtual Host

  1. 1 Install Virtual Host di perangkat
  2. 2 Buka → SELECT HOSTS FILE
  3. 3 Klik tombol "Unduh Host" di bawah
  4. 4 Pilih file Host yang sudah di download
  5. 5 Buka Growtopia → Play → name server AURIX
Download Virtual Host App Unduh Host

iOS / Surge 5

  1. 1 Install Surge 5 di iPhone/iPad
  2. 2 Klik tombol "Salin Konfigurasi" di bawah
  3. 3 Buka Surge → Import dari clipboard
  4. 4 Aktifkan → buka Growtopia → name server LucidPS
Download Surg

Windows

  1. 1 Tekan Win+R → ketik C:\Windows\System32\drivers\etc
  2. 2 Edit file hosts dengan Notepad (Run as Administrator)
  3. 3 Klik tombol "Salin IP" di bawah lalu Paste
  4. 4 Save → buka Growtopia → name server LucidPS
