❓ FAQ

Q: Apakah saya harus memiliki server Discord?
A: Tidak. Server Discord akan disediakan oleh HTS.
Q: Apakah server akan menjadi milik saya?
A: Ya. Setelah setup selesai, server akan diserahkan sepenuhnya kepada Customer.
Q: Apakah server dibuat dari awal?
A: Ya. Server akan dibuat dan disusun dari awal sesuai kebutuhan dan permintaan pembeli.
Q: Berapa lama proses pengerjaan?
A: Proses pengerjaan kurang dari 15 menit untuk Discord. Untuk GTPS, estimasi 1 - 2 minggu tergantung kompleksitas.
Q: Apakah bisa request sesuai keinginan?
A: Bisa. Paket A (Discord) dan Paket Economy GTPS sudah termasuk request custom.
Q: Apakah bisa revisi?
A: Ya, gratis revisi 1 kali untuk Paket A dan Paket Economy GTPS.
Q: Apakah saya bisa menambahkan bot sendiri?
A: Bisa. Kamu dapat meminta bot tertentu untuk ditambahkan selama sesuai dengan kebutuhan server.
Q: Bagaimana cara melakukan pembayaran?
A: Pembayaran dilakukan sebelum pengerjaan dimulai.
Q: Apakah bisa refund?
A: Tidak. Refund tidak berlaku setelah pengerjaan dimulai.
Q: Apa itu Economy GTPS?
A: Sistem ekonomi dalam server GTPS yang mencakup Daily Levels / Rewards, Sumber Profit Player, dan sistem tambahan sesuai request.
Q: Apakah bisa request fitur GTPS sendiri?
A: Bisa. Paket Economy GTPS sudah termasuk custom request sesuai kesepakatan.
Q: Berapa lama garansi GTPS?
A: Free garansi 10 hari setelah serah terima.
