How to Play

Pilih aplikasi yang ingin digunakan!

Android APK

Hapus Growtopia asli dulu, lalu install APK ini.

Langsung login tanpa Virtual Host / PowerTunnel.

Download APK Indonesia

PowerTunnel

  1. 1 Download & instal PowerTunnel
  2. 2 Buka → titik 3 → Hosts → Settings
  3. 3 Paste link di bawah
  4. 4 Klik Connect → buka Growtopia
Download PowerTunnel
https://gtpshosting.web.id/raw/Indonesia

Virtual Host

  1. 1 Download & instal Virtual Host
  2. 2 Buka → RE-SELECT HOSTS FILE
  3. 3 Download host di link bawah
  4. 4 Pilih file → buka Growtopia
Download Virtual Host
https://gtpshosting.web.id/how-to-play/Indonesia

Windows

  1. 1 Tekan Win+R → ketik C:\Windows\System32\drivers\etc
  2. 2 Edit file hosts dengan Notepad
  3. 3 Copy IP di bawah & paste
  4. 4 Save → buka Growtopia
149.202.58.185 www.growtopia1.com 149.202.58.185 www.growtopia2.com

iOS / Surge 5

  1. 1 Install Surge di iPhone/iPad
  2. 2 Copy konfigurasi dari link bawah
  3. 3 Buka Surge → import dari clipboard
  4. 4 Aktifkan → buka Growtopia
